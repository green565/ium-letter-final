이움레터 GitHub Pages 업로드 안내

새 저장소 이름: ium-letter-final
예상 주소: https://green565.github.io/ium-letter-final/

1. ZIP을 압축 해제합니다.
2. GitHub에서 green565/ium-letter-final 저장소를 새로 만듭니다(Public).
3. Add file > Upload files에서 압축 해제된 파일과 폴더 전체를 업로드합니다. ZIP 자체를 업로드하지 마세요.
4. Commit changes를 누릅니다.
5. Settings > Pages > Deploy from a branch > main / (root) > Save.
6. 배포 완료 후 위 예상 주소로 접속합니다.

참고: 이 ZIP은 디자인 도구에서 내보낸 단일 페이지 프로토타입입니다. Netlify 전체 서비스의 원본 소스가 아니므로 동일한 기능을 보장하지 않습니다.
